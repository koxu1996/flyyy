flyyy

Turn your machines into a cloud.

Containers run as Cloud Hypervisor microVMs across all of them, scale in seconds, and the edges balance every request.

Sign in

With your API token. It stays in this tab.

Where do I get a token?

The operator creates one for you:

flyyy users create alice --org acme

The operator's own is on the control host, in /var/lib/flyyy-operator/token.
